## 自动验证

对新增源码真实编译产物执行以下测试，不是单独用 Python 重写算法后测试。

- TC16 反汇编到等价 Thumb 的转换逐条校验长度，保留字面量地址；Unicorn 执行，传感器/蓝牙调用显式建模。
- BMP280 官方参考标定/ADC 向量：25.08℃ / 100653Pa。
- BMP 地址 0x76 和 0x77；AHT 湿度 0%、50%、最大原始值。
- 错 CRC、NACK、无效标定、无效原始值、busy、超时均不提交有效新样本。
- AHT 异步初始化、计时器回绕。
- 扫描响应重复更新、空间不足、异常 AD、API 忙。
- 100 组确定种子随机 64 位乘/除对照；调用保持被调用者寄存器和栈平衡。
- 编译 GPIO 在 SCL 固定低/无传感器 NACK 时有限退出并释放线路；未验证实际波形。
- 五处真实镜像入口结构、目标范围，等价尾跳转执行检测/初始化/触发/读取。
- 当前抓取的网页原始校验函数：原版和 R2 返回 ok；R1 对齐错误被重现；损坏 CRC/长度被拒绝。
- 原始输入精确哈希守卫，未授权字节不变；额外副本恢复到原版逐字节一致；坏恢复输入被拒绝。

构建命令和原始输出仅保存在本机 `build/commands.json`，避免上传用户名/绝对路径；可发布的精简报告在 `verification/`。这不是静态代码阅读的自我宣称，也不是硬件全系统仿真。

## 仍未验证

1. 实际读数独立确认来自 BMP280 + AHT20，而非原 U1 或原版回退。
2. 完整启动路径、电源/睡眠保持、真实 I²C 时序和重试对 BLE 的影响。
3. 主动扫描中的真实气压字段及持续可见性，Home Assistant 接入。
4. 网关联动、长期运行、电池电流/寿命，以及 U1 拆除后工作。
5. 实际设备端回退/救砖路径。

因此本项目始终标为 **experimental**，不作为已完成全部硬件验收的固件发布。
